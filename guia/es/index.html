Qué es

Un kit de decisión, no una reseña de producto

Creado por Mark Kashef y publicado bajo licencia MIT. Este repositorio conserva intacto el material original y agrega la traducción completa al portugués.

🧭 Elige el camino, no la marca

Primero decide el modelo operativo: quedarte donde estás, usar un asistente administrado, un runtime open source o un sistema propio. Recién después entra el nombre del producto.

🔬 Basado en evidencia

Antes de recomendar, realiza una entrevista, registra la fecha y las fuentes de la investigación y distingue lo que viene listo de fábrica del potencial que se puede alcanzar con trabajo.

🛡️ Antihype por diseño

Una novedad en redes sociales no es motivo para migrar. No hagas ningún cambio sin una prueba reversible previa y un piloto de siete días con criterio de salida.

Cómo funciona

Cinco etapas, un archivo de referencia para cada una

La skill no responde de inmediato: guía el proceso que aparece a continuación, y cada etapa tiene su propio archivo en references/.

Entrevista→ Investigación fechada→ Modelo de decisión→ Dossiers→ Paquete de decisión

1 · Entrevista adaptativa

Hasta 2 rondas, con un máximo de 3 preguntas por ronda. Si no señalas una falla recurrente real, «quedarte donde estás» se convierte en la hipótesis principal.

2 · Investigación con fecha

Registra la fecha, las URLs abiertas y los commits inspeccionados. Si no hay navegación disponible, usa los dosieres fechados y avisa qué hay que volver a verificar.

3 · Diez capas comparadas

Modelo y enrutamiento, runtime, archivos, herramientas, memoria, skills, rutinas, interfaces, permisos y mantenimiento: configuración de fábrica frente al límite alcanzable.

Requisitos previos

El camino más corto no requiere instalar nada

Hay tres formas de usarlo, en orden creciente de esfuerzo. La primera funciona en cualquier chat.

Ninguno · solo copiar y pegar

Abre el archivo del prompt y pega todo el contenido en cualquier IA capaz. La entrevista se desarrolla dentro de la conversación.

# el archivo que debes copiar
kit/prompts/PASTE-INTO-ANY-AI.md

Claude Code o Codex

Para instalarlo como skill, basta con uno de los dos en tu entorno. La carpeta ya viene en un formato válido de Agent Skill.

# comprueba que exista
ls ~/.claude/skills

Internet · para el mapa

El HTML local del mapa pesa 1,3 KB: es solo una redirección. El mapa interactivo real está en línea.

# el archivo local es una redirección
kit/website/OPEN-THE-AI-ASSISTANT-MAP.html
Guía de uso · paso a paso

Del clon al paquete de decisión

Comandos reales. Elige el paso 2 o el paso 3 — no necesitas los dos.

1

Clona el repositorio

Incluye el kit original, los dos zips intactos y la traducción al portugués.

git clone https://github.com/inematds/ai-assistant-decision-kit
cd ai-assistant-decision-kit
2

Opción A — sin instalar nada

Copia todo el prompt y pégalo en Claude, ChatGPT o Codex. Hay una versión original y otra traducida.

# original en inglés
cat kit/prompts/PASTE-INTO-ANY-AI.md

# traducción al portugués
cat traducao/prompts/PASTE-INTO-ANY-AI.md
3

Opción B — instalar como skill

Basta con un symlink. Instala siempre el original en inglés — la traducción es para leer, no para ejecutar.

# Claude Code
ln -s ~/projetos/ai-assistant-decision-kit/kit/ai-assistant-system-advisor \
      ~/.claude/skills/ai-assistant-system-advisor

# Codex
ln -s ~/projetos/ai-assistant-decision-kit/kit/ai-assistant-system-advisor \
      ~/.codex/skills/ai-assistant-system-advisor
4

Ejecuta la auditoría

Pídelo en lenguaje natural. El modo predeterminado es la auditoría completa de decisión.

# en Claude Code o Codex
Use the AI Assistant System Advisor to help me
decide which setup fits my real work.
5

Elige el modo adecuado

Son cuatro. Nombrar el modo ahorra una ronda de entrevista.

# auditoría de cambio — ¿vale la pena salir de mi configuración?
Run a switch audit: should I move from X to Y?

# análisis profundo de un producto
Do a product deep dive on Hermes Agent.

# arquitectura propia
Draft an owned-system blueprint for my requirements.
6

Abre el mapa interactivo

Cinco asistentes destacados, análisis de arquitectura, tabla de tiers arrastrable y mapa combinado de capacidades.

https://ai-assistant-house-map.markkashef.chatgpt.site/
7

Leer en portugués

Se tradujo toda la documentación, manteniendo los mismos nombres de archivo del kit.

# índice de las traducciones + glosario adoptado
cat traducao/README.md
Dossiers

Seis caminos, un archivo cada uno

En la auditoría completa, la skill los lee todos. En los otros modos, solo los que interesan para el caso.

🤖 Grok Bot

Administrado. Bot de xAI integrado al ecosistema de X.

🔧 Hermes Agent

Open source con el harness expuesto: loop, memoria curada, skills, subagentes y cron. Multimodelo.

🟣 Claude Cowork

Administrado. Entorno de Anthropic orientado al trabajo colaborativo.

🟢 ChatGPT Work

Administrado. Oferta de OpenAI para el trabajo y los conectores empresariales.

🐾 OpenClaw

Runtime open source para ejecutar en infraestructura propia.

🏗️ Sistema propio (DIY)

Arquitectura independiente del modelo, creada a partir de tus requisitos.
