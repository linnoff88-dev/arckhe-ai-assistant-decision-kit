Stop rebuilding the same assistant somewhere else

What it is

A decision kit, not a product review

Created by Mark Kashef and published under the MIT license. This repository keeps the original material intact and adds the complete Portuguese translation.

🧭 Choose the path, not the brand

First decide on the operating model — stay where you are, use a managed assistant, an open-source runtime, or a system of your own. Only then consider the product name.

🔬 Evidence-driven

Conducts an interview before making a recommendation, records the research date and sources, and separates what's available out of the box from what's achievable with work.

🛡️ Anti-hype by design

Social media buzz isn’t a reason to migrate. Don’t make a move without first testing it reversibly — and running a seven-day pilot with an exit criterion.

How it works

Five steps, one reference file for each

The skill doesn't answer right away: it guides you through the process below, and each step has its own file at references/.

Interview→ Dated research→ Decision model→ Dossiers→ Decision kit

1 · Adaptive interview

Up to 2 rounds, with no more than 3 questions per round. If you don't identify a genuinely recurring issue, "staying where you are" becomes the leading hypothesis.

2 · Timestamped research

Records the date, opened URLs, and inspected commits. If browsing isn’t available, it uses the dated dossiers and notes what needs to be rechecked.

3 · Ten layers compared

Model and routing, runtime, files, tools, memory, skills, routines, interfaces, permissions, and maintenance — out-of-the-box defaults versus the attainable ceiling.

Prerequisites

The shortest path doesn’t require installing anything

There are three ways to use it, in order of increasing effort. The first works in any chat.

None · just copy and paste

Open the prompt file and paste its entire contents into any capable AI. The interview runs within the conversation.

Claude Code or Codex

To install it as a skill, you only need one of the two in your environment. The folder is already in a valid Agent Skill format.

# check that it exists

Internet · for the map

User Guide · step by step

From clone to decision package

Real commands. Choose step 2 or step 3 — you don’t need both.

1

Clone the repository

Includes the original kit, both zips intact, and the Portuguese translation.

git clone https://github.com/inematds/ai-assistant-decision-kit
cd ai-assistant-decision-kit
2

Path A — install nothing

Copy the entire prompt and paste it into Claude, ChatGPT, or Codex. The original and translated versions are available.

# original in English
cat kit/prompts/PASTE-INTO-ANY-AI.md

# translation into Portuguese
cat traducao/prompts/PASTE-INTO-ANY-AI.md
3

Path B — install as a skill

A symlink is enough. Always install the original em inglês — the translation is for reading, not execution.

# Claude Code
ln -s ~/projetos/ai-assistant-decision-kit/kit/ai-assistant-system-advisor \
      ~/.claude/skills/ai-assistant-system-advisor

# Codex
ln -s ~/projetos/ai-assistant-decision-kit/kit/ai-assistant-system-advisor \
      ~/.codex/skills/ai-assistant-system-advisor
4

Run the audit

Ask in natural language. The default mode is the full decision audit.

# in Claude Code or Codex
Use the AI Assistant System Advisor to help me
decide which setup fits my real work.
5

Choose the right mode

There are four. Naming the mode saves an interview round.

# switch audit — is it worth leaving my setup?
Run a switch audit: should I move from X to Y?

# deep dive into a product
Do a product deep dive on Hermes Agent.

# custom architecture
Draft an owned-system blueprint for my requirements.
6

Open the interactive map

Five featured assistants, architecture cuts, a draggable tier chart, and a combined capability map.

https://ai-assistant-house-map.markkashef.chatgpt.site/
7

Read in Portuguese

The entire documentation has been translated, using the same file names as the kit.

# translation index + adopted glossary
cat traducao/README.md

Limits and license

What this material isn’t

Good to know before treating any number here as permanently true.

Date
The research has a date lockThe dossiers are fixed at 08/23/2026 and the map at 08/21/2026. Pricing, limits, and availability change quickly — when browsing is available, the skill rechecks primary sources.
Authorship
Third-party materialThe guide, prompt, and skill are by Mark Kashef, under the MIT license. This repository keeps kit/, origem/ e zips/ as a faithful copy of upstream.
Translation
The translation is our derivative workLives in traducao/, outside the upstream, as the MIT license allows. For reading; to run it, always use the original in English.
Scope
Doesn’t replace your judgmentThe decision kit delivers a verdict, fit table, runner-up, inventory of what you’d lose, and a pilot with an exit criterion — but you make the final choice.
