Pare de reconstruir o mesmo assistente em outro lugar

Toda semana sai um assistente de IA novo e o seu setup atual parece obsoleto. Este kit inverte a pergunta: em vez de "qual é o melhor?", ele apura o que de fato falha no seu trabalho hoje — e quase sempre a resposta certa é ficar onde está.

O que é

Um kit de decisão, não uma resenha de produto

Criado por Mark Kashef e publicado sob licença MIT. Este repositório guarda o material original intacto e acrescenta a tradução completa em português.

🧭 Escolhe o caminho, não a marca

Primeiro decide o modelo operacional — ficar onde está, assistente gerenciado, runtime open-source ou sistema próprio. Só depois entra o nome do produto.

🔬 Orientado a evidência

Entrevista antes de recomendar, registra data e fontes da pesquisa, e separa o que vem pronto de fábrica do teto que dá para alcançar com trabalho.

🛡️ Anti-hype por construção

Novidade em rede social não é motivo para migrar. Nenhum movimento sem teste reversível antes — e um piloto de sete dias com critério de saída.

Como funciona

Cinco etapas, um arquivo de referência para cada

A skill não responde de imediato: ela conduz o processo abaixo, e cada etapa tem seu próprio arquivo em references/.

Entrevista→ Pesquisa datada→ Modelo de decisão→ Dossiês→ Pacote de decisão

1 · Entrevista adaptativa

Até 2 rodadas, no máximo 3 perguntas por rodada. Se você não apontar uma falha recorrente de verdade, "ficar onde está" vira a hipótese principal.

2 · Pesquisa com carimbo

Registra data, URLs abertas e commits inspecionados. Sem navegação disponível, usa os dossiês datados e avisa o que precisa ser reverificado.

3 · Dez camadas comparadas

Modelo e roteamento, runtime, arquivos, ferramentas, memória, skills, rotinas, interfaces, permissões e manutenção — padrão de fábrica versus teto alcançável.

Pré-requisitos

O caminho mais curto não exige instalar nada

Há três formas de usar, em ordem crescente de esforço. A primeira funciona em qualquer chat.

Nenhum · só copiar e colar

Abra o arquivo do prompt e cole o conteúdo inteiro em qualquer IA capaz. A entrevista roda dentro da conversa.

# o arquivo a copiar
kit/prompts/PASTE-INTO-ANY-AI.md

Claude Code ou Codex

Para instalar como skill, basta um dos dois no seu ambiente. A pasta já vem no formato Agent Skill válido.

# confira que existe
ls ~/.claude/skills

Internet · para o mapa

O HTML local do mapa tem 1,3 KB — é só um redirect. O mapa interativo de verdade está online.

# o arquivo local é redirect
kit/website/OPEN-THE-AI-ASSISTANT-MAP.html
Guia de uso · passo a passo

Do clone ao pacote de decisão

Comandos reais. Escolha o passo 2 ou o passo 3 — não precisa dos dois.

1

Clone o repositório

Traz o kit original, os dois zips intactos e a tradução em português.

git clone https://github.com/inematds/ai-assistant-decision-kit
cd ai-assistant-decision-kit
2

Caminho A — sem instalar nada

Copie o prompt inteiro e cole no Claude, ChatGPT ou Codex. Existe a versão original e a traduzida.

# original em inglês
cat kit/prompts/PASTE-INTO-ANY-AI.md

# tradução em português
cat traducao/prompts/PASTE-INTO-ANY-AI.md
3

Caminho B — instalar como skill

Um symlink basta. Instale sempre o original em inglês — a tradução é para leitura, não para execução.

# Claude Code
ln -s ~/projetos/ai-assistant-decision-kit/kit/ai-assistant-system-advisor \
      ~/.claude/skills/ai-assistant-system-advisor

# Codex
ln -s ~/projetos/ai-assistant-decision-kit/kit/ai-assistant-system-advisor \
      ~/.codex/skills/ai-assistant-system-advisor
4

Rode a auditoria

Peça em linguagem natural. O modo padrão é a auditoria completa de decisão.

# no Claude Code ou Codex
Use the AI Assistant System Advisor to help me
decide which setup fits my real work.
5

Escolha o modo certo

São quatro. Nomear o modo economiza uma rodada de entrevista.

# auditoria de troca — vale sair do meu setup?
Run a switch audit: should I move from X to Y?

# mergulho num produto
Do a product deep dive on Hermes Agent.

# arquitetura própria
Draft an owned-system blueprint for my requirements.
6

Abra o mapa interativo

Cinco assistentes em destaque, cortes de arquitetura, quadro de tiers arrastável e mapa combinado de capacidades.

https://ai-assistant-house-map.markkashef.chatgpt.site/
7

Leia em português

A documentação inteira foi traduzida, espelhando os mesmos nomes de arquivo do kit.

# índice das traduções + glossário adotado
cat traducao/README.md
Dossiês

Seis caminhos, um arquivo cada

Na auditoria completa a skill lê todos. Nos outros modos, só os que interessam ao caso.

🤖 Grok Bot

Gerenciado. Bot da xAI integrado ao ecossistema do X.

🔧 Hermes Agent

Open-source com o harness exposto: loop, memória curada, skills, subagentes e cron. Multi-modelo.

🟣 Claude Cowork

Gerenciado. Ambiente da Anthropic voltado a trabalho colaborativo.

🟢 ChatGPT Work

Gerenciado. Oferta da OpenAI para trabalho e conectores corporativos.

🐾 OpenClaw

Runtime open-source para rodar em infraestrutura própria.

Arquitetura agnóstica de modelo, montada a partir dos seus requisitos.
