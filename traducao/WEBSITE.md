# Mapa Interativo de Assistentes de IA

Abra o mapa:

https://ai-assistant-house-map.markkashef.chatgpt.site/

## Como usar

- Comece por `They use the same core parts` para entender a categoria.
- Percorra cada assistente para conhecer o setup dele, o motivo da fama, a arquitetura e o trade-off.
- Use o quadro de tiers para classificar segundo a sua própria ótica.
- Termine com o mapa de capacidades combinado e passe o cursor ou toque no logotipo de um provedor para isolar o que ele acrescenta.

## Trava de pesquisa

A comparação filmada foi pesquisada até 21 de agosto de 2026. Recursos, preços, limites e disponibilidade dos produtos podem mudar. Consulte os links das fontes no rodapé do mapa ao vivo para obter informações atuais de primeira parte.
